# Scarp 0.0.4-dev — unreleased function candidate

This is a development build on `scarp/funcra-main`, based on public beta.2 source
`be9cfa5eaf05c0c895a7a8c377642c3d79c8ad0b`. No v0.0.4 tag or public prerelease
has been created. Use [v0.0.3-beta.2](v0.0.3-beta.2.md) for published downloads.

The candidate adds typed file-level `funcra`, positional/named/default arguments,
forward/mutual recursion, explicit returns and unit results, purity, needs/ensures,
heap call frames, bounded call traces, and immutable signature/call-graph metadata.
Functions support integer/string/boolean values. Existing repeat counts may call
functions and are still evaluated once. See [the full guide](../functions.md).

Compatibility: existing embedding function signatures and two-field
ExecutionLimits literals are preserved. New options impose default call,
live-slot, and snapshot caps. Syntax hosts must update exhaustive public enum
matches. Function words become reserved; unknown calls report E0023. Existing
E0001–E0019 codes, bind/var syntax, output spellings, loop behavior, and CLI
commands are retained. Published beta.2 source and assets remain unchanged.

This adapts only the function core of PR #27 and fixes from #37. It contains no
decimal/vector/numeric builtin/bit-operation/native compiler or CLI redesign
integration. `scarp compile` remains unsupported, producing no native artifact.
Functions are interpreted; performance equivalence to native languages is not
claimed. Logical execution caps do not bound all parsing or process memory.

Native CI packages are development artifacts for Windows x64 MSVC, Linux x64 GNU,
and Apple Silicon macOS. They contain 18 exact-output examples and BUILD-INFO
with the source SHA, compiler, target, version, and clean state. Any eventual
public release requires a separately reviewed version decision, exact-final-main
green CI, verified checksums, and publication confirmation.
