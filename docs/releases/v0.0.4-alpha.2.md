## Included

- Immutable finite binary64 vector literals, checked zero-based indexing and
  length, whole-vector replacement, shared value/output snapshots and equality.
- Vector parameters/results/defaults, named user arguments, recursion, pure
  kernels, needs/ensures contracts and bounded heap frames.
- Ten positional kernels: len, sum, mean, dot, mse, add, scale, clamp, fill and
  softmax. Fill order is float value then integer count; no implicit conversions.
- Compensated reductions, overflow-resistant mean/MSE and maximum-shifted
  softmax. Underflow/subnormals are allowed; nonfinite stored values/results fail.
- At most 65,536 elements per vector; prepaid work and allocation, fallible
  buffer reservation, per-vector output preparation and logical snapshot bytes.
- E0032–E0035 add length, bounds, domain and allocation diagnostics. E0001–E0031,
  all six execution option fields and run/check/tokens spellings are preserved.
- Three executable numerical examples with exact fixtures, an independently
  computed softmax reference and verified native/interpreted benchmarks.

## Compatibility and remaining limits

Public token/AST/value/type enums and diagnostics gain vector variants. Exhaustive
Rust matches need updates. Integers and floats do not implicitly convert, arrays
are not mutable in place, and vector arithmetic uses kernels rather than operators.
Legacy scalar/function semantics and historical release files are preserved.

Work limits bound cumulative vector payload allocation; they do not bound all
parser/host/container memory. Snapshot caps count logical storage, not encoded
bytes. Native kernels use platform exponentials, so nontrivial softmax results
need tolerances. Ordered sum/dot can reject overflowing intermediates even when
later cancellation would make a result finite. No exact arithmetic is promised.

No tensors, differentiation, GPUs, native backend, bitwise stack, CLI rename,
imports, package manager, custom types or self-hosting. Future tensor design
should start from reviewed shape/stride/storage semantics and explicit memory
limits, not import the old experimental stack wholesale.
