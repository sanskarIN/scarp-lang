# Authorization for the source-modules prerelease

On 1 November 2026 the maintainer authorized publication of the candidate just
reported in the project chat: "You can pre-release for this". That candidate is
**0.0.5-alpha.1** from exact source
`afe8b5380c9d6c4774162e51c6c9bc8b90901671`, integrated by
[PR #66](https://github.com/sanskarIN/scarp-lang/pull/66).

The request in `.github/release-request.json` pins that source and the configured
maintainer tagger identity, Sanskar (`sanskarin@outlook.in`). It does not authorize
another version, a different source, replacement of published assets or a
repository transfer. The maintainer will transfer ownership after publication.

All four [source Rust jobs](https://github.com/sanskarIN/scarp-lang/actions/runs/41284598134)
and three [source native package jobs](https://github.com/sanskarIN/scarp-lang/actions/runs/41284598100)
passed. Downloaded native archives were verified against the approved Git tree,
clean build records, artifact digests and checksums. The Windows download also
passed all 39 example outputs, silent checks and module failure probes.

The request's control revision must independently pass its own four Rust and
three package jobs before the existing guarded publisher can act. It must verify
the approved source again, create a new annotated tag, compare all draft asset
downloads, publish as a prerelease with `make_latest=false`, and verify all seven
public downloads. Preparation is not evidence of completed publication.

Release notes and packaged documentation come from the approved source. Their
candidate wording is an immutable preparation snapshot; a separate publication
record will identify the actual release state and verification evidence.
After public verification the completed request will be removed.

The planned destination is `scarp-lang/Scarp`. Ownership transfer and repository
rename remain maintainer actions after this release and its migration record
are ready. Historical tags, releases, useful branches and contribution history
must be preserved. No website or Pages deployment is included.
