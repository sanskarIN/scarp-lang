# Scarp v0.0.3-beta.1 — Iteration & Safe Execution

Experimental beta, 2026-10-27. This is a prerelease, not stable v0.0.3.

## Included

- The reviewed while/break/continue implementation from PR #16, integrated through
  #28 while preserving the published v0.0.2 notes and original feature branches.
- New `repeat count as index` counted loops with a saved integer count, immutable
  zero-based exclusive index, fixed storage, and nearest-loop control.
- Fresh deterministic limits: 1,000,000 work steps and 100,000 selected prints,
  with `--max-steps` / `--max-prints` for run/check and existing embedding APIs.
- Tab `\t` and carriage-return `\r` string escapes alongside backslash, quote, LF.
- Clear loop/count/index/budget diagnostics, contextual CLI help, iteration and
  budget guides, exact diagnostic fixtures, and raw-byte package verification.

```scarp
let mut total = 0;
repeat 5 as index {
    total += index;
}
println(total); // 10
```

The count is evaluated once before binding the index. Zero skips execution but
still type-checks the body. Negative counts fail with E0019. Continue advances a
repeat index or reevaluates a while guard; break exits the nearest loop. All
source/runtime/budget failures leave program output empty before replay. Writer
failures can leave earlier bytes. See [iteration](../iteration.md) and
[budgets](../budgets.md) for scope, work accounting, and examples.

## Compatibility and exclusions

Keep `let`, `let mut`, `println`, and `scarp run/check/tokens`. Check evaluates
selected arithmetic and loops silently; tokens only lexes. Existing v0.0.2
example sources and expected bytes are preserved and checked by a digest manifest.
Repeat/as stay contextual identifiers, including existing assignments to repeat.
Existing embedding function signatures and ExecutionLimits literals remain valid.
Public AST/diagnostic enum additions require exhaustive Rust match updates.

The default execution limits also bound previously unbounded programs. Print
limits bound selected statements, not string byte length. Limits do not bound
parse memory or act as a general sandbox. Both new escapes produce literal
control bytes; there is no interpolation or formatting system.

This beta excludes funcra/functions/closures, floats/vectors, bit operations,
native C/executable/object compilation, project/package managers, bind/var,
print/write/explicit stream syntax, and the exec/verify/inspect CLI redesign.
Those experimental branches remain separate. There is no stable v0.0.3 release
or package-registry publication.

## Downloads and verification

Use the [v0.0.3-beta.1 prerelease](https://github.com/sanskarIN/scarp-lang/releases/tag/v0.0.3-beta.1).

| Archive | Platform |
| --- | --- |
| scarp-0.0.3-beta.1-x86_64-pc-windows-msvc.zip | Windows x64 MSVC |
| scarp-0.0.3-beta.1-x86_64-unknown-linux-gnu.tar.gz | Linux x64 GNU, built on Ubuntu 22.04 |
| scarp-0.0.3-beta.1-aarch64-apple-darwin.tar.gz | Apple Silicon macOS |

Each archive has a `.sha256` file. `SHA256SUMS` combines all three digests.
Linux: `sha256sum --check <archive>.sha256`; macOS:
`shasum -a 256 -c <archive>.sha256`; Windows: compare
`(Get-FileHash ./<archive> -Algorithm SHA256).Hash` with the checksum file.
These are corruption checks, not signed provenance attestations.

Every package contains the binary, license, guides, all example sources/outputs,
and BUILD-INFO.txt recording version, target, exact commit, compiler, and clean
source state. Packages must come from the final reviewed main commit's successful
platform workflow, then pass checksum/source-record verification before upload.
Rust checks cover Windows/Linux/macOS and minimum Rust 1.74; native package jobs
extract and execute all fourteen examples plus budget/help/error checks.

After extraction:

```sh
./scarp --version
./scarp run examples/repeat.srp
./scarp check --max-steps 2000000 examples/loops.srp
```

Use `./scarp.exe` on Windows. Expected version: `scarp 0.0.3-beta.1`.
Repeat prints `8` and `0`, each followed by LF; check succeeds silently.
Downloaded native binaries do not require Rust. Source builds require Rust 1.74
or later; the project retains Rust 2021, zero third-party Rust dependencies,
`unsafe_code = "forbid"`, Apache-2.0, and `publish = false`.
