## Publication gate and provenance

The release preparation PR and final main revision must each pass their hosted
source/package checks, including Rust 1.74 and Windows/Linux/macOS. Only native
artifacts whose workflow head equals the final main commit may be published.
Package jobs extract and execute all 15 examples and verify explicit streams,
silent checks, budgets, diagnostics, version, and token inspection.

The release verifier checks all three archive hashes and companion checksums,
required files, Unix executable permissions, compiler/version/target records,
clean source state, and the exact final commit. The combined SHA256SUMS is made
from those verified files. Draft uploads are downloaded and reverified before
publication; public downloads are checked afterward.

The new annotated v0.0.3-beta.2 tag, its peeled commit, and package BUILD-INFO
records identify the authoritative source. Commit/tag email is
sanskarin@outlook.in. Existing tags and published assets remain immutable. The
release is a prerelease with latest=false and does not publish a registry crate.
The [release page](https://github.com/sanskarIN/scarp-lang/releases/tag/v0.0.3-beta.2)
