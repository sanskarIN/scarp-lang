# v0.0.3-beta.3 validation record

## Audited baseline

On 2026-10-29, the latest published version was v0.0.3-beta.2. Main was
`511dd5fe5955c1c48ce6918e6cfd51897773e1a9`, with temporary version 0.0.4-dev.
Functions had already been integrated through PR #41; numerical/native/CLI
experiments remained on the old separate stack. No beta.3 tag existed.

The baseline's exact-main hosted [Rust checks](https://github.com/sanskarIN/scarp-lang/actions/runs/40693752162)
and [native packages](https://github.com/sanskarIN/scarp-lang/actions/runs/40693752464)
passed. A fresh local baseline check using Rust 1.99.1 on Linux passed formatting,
Clippy with warnings denied, debug/release tests, rustdoc, builds, and script
examples: 572 test executions, zero failed or ignored. Python baseline package
verifier tests also passed.

## Changes and local validation

The release adds CLI controls for existing function/snapshot resource limits,
actionable diagnostics, six focused CLI regression tests, source-blob archive
verification, native package resource checks, and a separately gated one-version
publisher. Guides distinguish the older beta.2 from the integrated beta.3.
The unpublished 0.0.4-dev identifier is replaced with the user-requested beta.3;
no published version is reused.

Local checks use Rust 1.99.1 on Linux and Python 3.11 or later:

```sh
sh scripts/check.sh --offline
cargo bench --locked --offline --bench runtime -- --quick
python3 -m unittest discover -s scripts -p 'test_*release*.py'
```

The Python suite covers complete/damaged native archives, historical example
bytes, required function guides/examples, exact Git source matching, latest-CI
selection, incomplete matrices, and draft/public asset integrity. It passes all
26 tests. A separate focused run of CLI and function-diagnostic suites passed
44 tests before the full release check. The full script passed 584 test executions
(292 each in debug and release, including rustdoc), zero failed or ignored, plus
formatting, Clippy, builds, rustdoc generation, and all script examples. Four
benchmark smoke workloads verified output without a performance-parity claim.
Documentation QA passed 179 relative links, 34 valid Scarp programs and 14
expected-invalid programs. Hosted native PowerShell packaging and
Rust 1.74 checks are independent gates, not inferred from this Linux run.

The first native CI run exposed an empty-stream conversion in the added
PowerShell checks. The repaired harness compares run output as exact bytes and
checks validation output length directly. A full native Linux package was then
built, extracted, and smoke-tested locally with PowerShell 7.6.9, including all
18 examples and resource controls. This modified local package is diagnostic
evidence; publication uses only clean final-main hosted artifacts. All three
native jobs must be rerun on the repaired head.

The floating macos-latest Rust job remained queued after the other six gates
passed. GitHub runner-images lists macos-15 as a supported ARM image; the Rust
matrix is pinned to that image, with the publisher requiring its exact job
name. Native Apple Silicon package validation remains a separate gate. Fresh
CI on this final configuration is required before merge and publication.

## Final publication evidence

The publisher records the exact final-main SHA and both successful workflow URLs,
creates an annotated tag, verifies draft downloads, confirms prerelease state,
and verifies all seven public downloads. Those run URLs, source SHA and digests
are available through the release's repository Actions history and tag. Local
source preparation alone is not evidence that publication occurred.
