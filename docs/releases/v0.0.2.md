# Scarp v0.0.2 prerelease

**Build Beyond Boundaries.**

The variable milestone adds names, mutable state, scopes, strings, booleans,
and conditional statements to Scarp's checked interpreter. It integrates
PRs #7–#15 into main. Syntax and public Rust APIs remain experimental.

```scarp
let name = "Scarp";
let mut total = 1;
{
    let total = total + 10;
    println(total);
}
total += 2;
if total == 3 {
    println(name);
    println(total);
} else {
    println("unexpected");
}
```

```text
11
Scarp
3
```

## Included features

- Immutable `let` bindings and explicit `let mut` mutation.
- Assignment and checked `+=`, `-=`, `*=`, and `/=` statements.
- Lexical blocks, shadowing, and assignment to the nearest visible binding.
- Integer, string, and boolean values with inferred, fixed binding types.
- Same-kind comparisons and short-circuit `and`, `or`, and `not` logic.
- Scoped `if`/`elif`/`else` statements with boolean conditions.
- Name, mutability, type, and source diagnostics before execution.
- `scarp check` for silent validation, per-command help, and filename separators.
- Reusable expression workspace and reproducible stage benchmarks.
- Tutorials, references, embedding examples, and compatibility guidance.

Every execution starts with fresh storage. Prints capture values before later
mutation. Unselected conditional bodies are statically checked but do not
evaluate arithmetic. Source and semantic failures produce no program output;
an output-stream failure can leave bytes already written.

## Downloads and verification

Download the matching archive and its `.sha256` file from the
[v0.0.2 release](https://github.com/sanskarIN/scarp-lang/releases/tag/v0.0.2).
`SHA256SUMS` combines all three archive checksums.

| Archive | Platform |
| --- | --- |
| `scarp-0.0.2-x86_64-pc-windows-msvc.zip` | Windows x64 MSVC |
| `scarp-0.0.2-x86_64-unknown-linux-gnu.tar.gz` | Linux x64 GNU; built on Ubuntu 22.04 |
| `scarp-0.0.2-aarch64-apple-darwin.tar.gz` | Apple Silicon macOS |

On Linux, run `sha256sum --check <archive>.sha256`. On macOS, run
`shasum -a 256 -c <archive>.sha256`. On Windows, compare
`(Get-FileHash ./<archive> -Algorithm SHA256).Hash` with the checksum file.
Checksums detect corruption; these binaries and checksum files are not signed.

Each archive includes the executable, Apache-2.0 license, contribution guide,
documentation, examples and expected output, and `BUILD-INFO.txt`. Published
build records identify the exact tagged commit, native target, compiler, and
clean working tree. Each native package is extracted and smoke-tested before
upload. There are no installers or registry packages.

After extraction, open a terminal in the package directory:

```sh
./scarp --version
./scarp run examples/bindings.srp
./scarp run examples/mutable.srp
./scarp run examples/scopes.srp
./scarp run examples/decisions.srp
./scarp check examples/string_bindings.srp
```

Use `./scarp.exe` on Windows. Expected version: `scarp 0.0.2`.
Rust is only needed for source builds; Rust 1.74 or later is supported and
there are no third-party Rust dependencies. `publish = false` remains set.

## Library migration from v0.0.1

`parse(source)` returns unresolved syntax. `compile(source)` resolves names and
returns an immutable `ResolvedProgram`. Use `statement_count`, `binding_count`,
and `binding_types` to inspect metadata. `interpreter::execute` accepts the
resolved program; repeated calls use fresh storage and independent workspaces.
`check` and `interpreter::validate` validate without an output sink. `run` keeps
the source-plus-writer interface.

`PrintArgument::Integer` becomes `PrintArgument::Expression`. The `Value` and
`ValueType` enums support integers, strings, and booleans. `evaluator::evaluate`
retains the integer result API; `evaluate_value` supports all three kinds.
Rust hosts with exhaustive enum matches need to handle the additional variants.
See [compatibility](../compatibility.md) and [embedding](../embedding.md).

## Validation and limits

The release checks formatting, Clippy, debug/release tests, rustdoc, examples,
benchmark smoke workloads, minimum Rust 1.74.0, and native packages on Windows,
Linux, and macOS. Tests include generated scoped programs, concurrent reuse,
long flat expressions, 20,000 sibling blocks, combined nesting boundaries,
malformed source/tokens, and output failures.

Only the first error is reported. The interpreter reads the complete source,
keeps captured prints until validation succeeds, and permits 64 levels of
blocks and expression grouping independently. There are no user functions,
modules, custom types, or package manager. General performance parity with
C/C++ or Rust has not been established.

PRs #16–#20 remain separate: loops/budgets, decimals, numerical vectors, integer
bit operations, and experimental freestanding C emission are excluded from
v0.0.2. Further integration requires the maintainer's instruction.
