# Scarp v0.0.3-beta.2 — Variables and Output Polish

Experimental prerelease, 2026-10-28. This publishes the reviewed main declaration
and output changes after v0.0.3-beta.1, plus focused variable diagnostic repairs.
No new language feature is introduced in this maintenance pass.

## Included

- Immutable `bind` and mutable `var` declarations with the existing scope,
  shadowing, primitive typing, checked arithmetic, and value-snapshot rules.
- Canonical `print`, raw `write`, explicit `eprint`/`ewrite`, zero/multiple
  arguments, and optional trailing commas. `println` remains an exact alias.
- Explicit dual-writer library APIs and CLI routing. Selected output is prepared
  before either stream receives bytes; source/runtime/budget failures discard it.
- Contextual repairs for incomplete declarations and assignments, with unchanged
  error codes and precise spans. More specific expression errors keep their help.
- Reviewed while/repeat loops, nearest-loop break/continue, saved repeat counts,
  default work/output budgets, and all five existing string escapes.

```scarp
bind step = 2;
var total = 0;
repeat 3 as index {
    total += step;
}
write("total: ");
print(total);
```

Exact stdout: `total: 6\n`. `scarp check` evaluates this program silently.

## Upgrade from beta.1

Replace declaration tokens `let` with `bind` and `let mut` with `var`.
Legacy declarations produce E0005 and migration help before output. Strings and
comments retain their text. See the [migration guide](../syntax-migration.md).
The original v0.0.2 examples remain preserved as exact historical fixtures.

Use `print` for ordinary line output and `write` to continue the same line.
Adjacent arguments display with one ASCII space. Generated line endings are LF
on every platform. Empty raw writes emit nothing but still count against the
selected-output budget. See [output](../output.md) and [budgets](../budgets.md).

Existing single-writer Rust entry points retain their signatures. A selected
nonempty stderr event requires the additive dual-writer API and otherwise fails
before stdout. Writer failures during replay can leave earlier bytes. Syntax
hosts must update `Statement::Let` to `Statement::Declaration` and handle the
additive `Statement::Output`, `OutputTarget`, and `TokenKind::Comma` variants.

Commands remain `run`, `check`, `tokens`, help, and version. This package supports
checked signed i64, strings, and booleans. Functions remain on the separate
development stack in PRs #27 and #37. Their diagnostic improvements are not
included in these main binaries. Floats/vectors, native compilation, closures,
and the CLI redesign also remain outside this release.

## Downloads and verification

The [prerelease](https://github.com/sanskarIN/scarp-lang/releases/tag/v0.0.3-beta.2)
contains native archives for Windows x64 MSVC, Linux x64 GNU (Ubuntu 22.04), and
Apple Silicon macOS. Each archive includes the binary, license, documentation,
all 15 examples and expected outputs, and a build record containing version,
target, compiler, clean source state, and the exact release commit.

Three `.sha256` files and the combined `SHA256SUMS` cover the three archives.
Use `sha256sum --check` on Linux, `shasum -a 256 -c` on macOS, or compare
`Get-FileHash -Algorithm SHA256` on Windows. Checksums detect corruption and are
not signed provenance attestations. The annotated tag and build records identify
the reviewed source; packages are taken only from its successful native jobs.

```sh
./scarp --version
./scarp run examples/output.srp
./scarp check examples/repeat.srp
```

Use `./scarp.exe` on Windows. Expected version: `scarp 0.0.3-beta.2`.
The raw-output example ends in `done` without a final newline. `check` succeeds
silently. Source builds retain Rust 2021, Rust 1.74 minimum, zero third-party Rust
dependencies, forbidden unsafe code, Apache-2.0, and `publish = false`.

Earlier published tags and packages remain unchanged. This is not stable
v0.0.3 and does not publish a package-registry crate.
