# Scarp v0.0.1 prerelease

**Build Beyond Boundaries.**

This is Scarp's first experimental interpreter prerelease. It introduces a real
lexer, parser, checked integer evaluator, interpreter, and command-line interface.
Language syntax and library APIs are experimental.

```scarp
println("Hello from Scarp!");
println(1 + 2 * 3);
println((1 + 2) * 3);
```

```text
Hello from Scarp!
7
9
```

Strings support Unicode text and the escapes `\\`, `\"`, and `\n`. Integer
expressions support `+`, `-`, `*`, `/`, unary minus, and grouping. Arithmetic is
checked in all build modes; overflow and division by zero produce source
diagnostics. Invalid programs produce no partial program output.

## Downloads

| Archive suffix | Platform |
| --- | --- |
| `x86_64-pc-windows-msvc.zip` | Windows x64 |
| `x86_64-unknown-linux-gnu.tar.gz` | Linux x64, GNU libc |
| `aarch64-apple-darwin.tar.gz` | Apple Silicon macOS |

Each archive contains the executable, Apache-2.0 license, README, changelog,
examples with expected output, language documentation, and `BUILD-INFO.txt`.
The build record identifies the exact source commit, target, compiler, and
working-tree state. Linux packages are built on Ubuntu 22.04 and require a
compatible GNU libc runtime. The macOS archive is for Apple Silicon, not Intel.
There are no installers or registry packages in this prerelease.

Download the archive matching your platform and its `.sha256` file from this
release. `SHA256SUMS` contains all archive checksums. Verify before extracting:

```sh
# Linux
sha256sum --check scarp-0.0.1-x86_64-unknown-linux-gnu.tar.gz.sha256

# macOS
shasum -a 256 -c scarp-0.0.1-aarch64-apple-darwin.tar.gz.sha256
```

On Windows, compare the hash printed by `Get-FileHash` with the downloaded
checksum file:

```powershell
(Get-FileHash ./scarp-0.0.1-x86_64-pc-windows-msvc.zip -Algorithm SHA256).Hash
Get-Content ./scarp-0.0.1-x86_64-pc-windows-msvc.zip.sha256
```

Hashes are case-insensitive. The checksums detect corruption; the binaries and
checksum files are not cryptographically signed.

## Run after extraction

Open a terminal in the extracted directory. On Linux and macOS:

```sh
./scarp --version
./scarp run examples/hello.srp
./scarp run examples/arithmetic.srp
./scarp tokens examples/arithmetic.srp
```

On Windows, use `./scarp.exe` in place of `./scarp`. The executable can also be
placed in a directory on your `PATH`.

Rust is needed only when building from source. The repository has no third-party
Rust dependencies and requires Rust 1.74 or later:

```sh
cargo build --locked --release
cargo run --locked -- run examples/arithmetic.srp
```

## Validation and limits

The release is gated on formatting, Clippy, debug and release tests, rustdoc,
examples, minimum Rust checks, and native package smoke tests. Each archive is
extracted and its executable is checked for version, string/arithmetic output,
and a failure case before upload.

This is a tree-walking interpreter, not a native compiler. Bindings, functions,
types, modules, loops, and package management remain future work. Only the first
error is reported, all source is read into memory, and expression grouping is
limited to 64 levels. See the included language reference for exact semantics.

The next focused milestone is immutable integer bindings and name resolution.
