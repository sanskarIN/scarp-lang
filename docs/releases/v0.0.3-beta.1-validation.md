## Compatibility correction and boundaries

The final audit caught that the new escape example had reused the existing
escapes.srp filename. PR #32 restored the original pair byte-for-byte and moved
the new program to control_escapes. A digest manifest now locks all 22 original
source/output files. Package discovery verifies all 14 shipped programs rather
than relying on an incomplete manual list. Historical v0.0.2 release notes and
all previously issued tags/assets are unchanged.

Repeat uses two fixed integer slots and flat jumps. Count is evaluated once;
continue advances repeat or rechecks while. Static checking includes skipped
bodies. Runtime/budget failures discard pending output. The existing public
ExecutionLimits and embedding signatures remain; exhaustive AST/diagnostic enum
matches need the documented additions. E0019 was the next free code on this
release baseline. Separate experimental stacks must reconcile their interfaces
when eventually integrated; they are not supported by this beta.

## Release provenance gate

The beta version is 0.0.3-beta.1; no stable v0.0.3 or registry package is created.
After the release PR merges, final main Rust/package runs must succeed. Download
only artifacts whose workflow head equals that exact commit. The verifier checks
three archive hashes, their checksum files, required iteration fixtures, Unix
executable bits, beta version, compiler record, clean tree, and exact source SHA.
It rejects stale-version records and modified-tree assets. The combined
SHA256SUMS is generated from those verified archives.

The new annotated tag must point to that reviewed main commit and may never
replace an existing tag. Verify a draft's seven uploaded assets before publishing
it as a prerelease with latest=false. The authoritative final commit is the
peeled v0.0.3-beta.1 tag and each package's BUILD-INFO.txt. Asset digests and the
published state are recorded on the [GitHub prerelease](https://github.com/sanskarIN/scarp-lang/releases/tag/v0.0.3-beta.1).
No performance comparison with C/C++/Rust, general sandbox, native Scarp compiler,
or completion of deferred function/numerical features is claimed.
