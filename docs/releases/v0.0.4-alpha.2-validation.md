# Alpha.2 engineering validation record

The numerical milestone was integrated through
[PR #48](https://github.com/sanskarIN/scarp-lang/pull/48). Baseline alpha.1 source
was `3b65b7dc93d57ff47966faaeb192b09d57f65a8a`; accepted numerical checkpoint
was `4c78a3949a0e4f58457ba01e3aebe1e0d39f6b13` on 2026-10-30.

This record describes that engineering checkpoint. Later documentation and
scheduling changes require fresh exact-main checks and artifacts; its archive
digests must not be reused as the final release's digests.

## Verified checkpoint

| Evidence | Result |
| --- | --- |
| Full PowerShell and shell scripts on Windows | Passed fmt, Clippy warnings denied, build, rustdoc and examples |
| Debug and release suites | 351 tests in each mode, up from 319 in alpha.1 |
| Release-tool tests | 40 passed at the numerical checkpoint |
| Documentation | 56 Scarp fences, eight compiled/executed Rust hosts, 227 local links |
| Runnable examples | All 23 stdout fixtures and silent checks passed |
| Stable Windows/Linux/macOS and Rust 1.74 | [Four source jobs passed](https://github.com/sanskarIN/scarp-lang/actions/runs/41031611081) |
| Three supported native archives | [All package jobs passed](https://github.com/sanskarIN/scarp-lang/actions/runs/41031611385) |

The first macOS debug run exposed a stack overflow at combined block/expression
limits. Parser container/leaf/atom state and internal errors were refactored;
a 512 KiB parser regression covers grouped scalars/vectors and nested calls.
The existing 64-level limits and earlier tests were preserved. Fresh macOS and
minimum-Rust runs passed after the fix.

Downloaded checkpoint archives were verified against every packaged Git source
blob, clean BUILD-INFO records, target/version/commit/compiler, executable
permissions, individual SHA-256 and combined SHA256SUMS. The extracted Windows
binary independently passed all 23 packaged examples and silent checks.

## Numerical and performance evidence

Tests cover all ten kernels, function defaults/named calls/returns/contracts,
pure calls, recursive/concurrent reuse, all six exact resource boundaries,
dual-stream atomicity, malformed/Unicode input and long flat postfix chains.
Reduction references use integer numerators; 37 softmax cases were computed
independently with 60-digit Decimal exponentials. Mean/MSE tests include cases
whose naive intermediates overflow, signed zero, subnormals and cancellation.

[Performance records](../performance.md#numerical-vector-measurements) identify
the exact measured source, compiler, CPU, workload, phase and repetition counts.
Kernel/indexed dot validation ratios were 5.2–5.9x for 16 and 29.0–35.1x for
32,768 elements on that Windows machine. Absolute timings varied; no general
compiled-language parity or timing threshold is asserted.

## Publication evidence is separate

The numerical checkpoint created no alpha.2 tag or release. The maintainer later
requested publication for 31 October at 10:00 AM IST. The
[release process](../releasing.md) describes its explicit time window, retry
schedule and cancellation. A scheduled attempt must independently verify its
own exact-main source/package runs and all seven assets, then verify draft and
public downloads. The release page and publisher summary record actual source,
publication time and final digests after publication.

The [alpha.2 release page](https://github.com/sanskarIN/scarp-lang/releases/tag/v0.0.4-alpha.2)
is the publication status record. Existing alpha.1 and older tags/assets remain
unchanged. A prepared version, successful build or calendar plan alone is not
evidence that a public release exists.
